# cs-practice
Рабочая папка — директория проекта, где хранится репозиторий и отслеживаемые файлы.
Индекс (staging area) — область подготовки изменений: git add lab02/NOTES.md помещает файл в индекс, git diff --staged показывает различия между индексом и последним коммитом.
Коммит — зафиксированное состояние репозитория: git commit -m "Describe local Git states" сохраняет изменения из индекса в историю.
Git — локальная распределённая система контроля версий (работает на машине, фиксирует коммиты, управляет ветками). 
GitHub — облачная платформа для хостинга Git‑репозиториев (обеспечивает удалённое хранение, коллаборацию, PR, CI/CD).
git status — отображает текущее состояние репозитория: отслеживаемые/неотслеживаемые файлы, изменённые файлы, ветку, наличие неотправленных коммитов.
git diff — показывает различия между рабочей директорией и индексом (незастаджированные изменения).
git diff --staged — показывает различия между индексом и последним коммитом (застаджированные изменения).
Ветка в Git — это указатель (ссылка) на конкретный коммит. Не копия файлов и не отдельная папка, а просто метка «вот здесь сейчас конец этой линии разработки».
Git берёт текущее состояние рабочей директории, добавляет изменённые файлы в индекс (git add), затем фиксирует снимок состояния — создаёт новый коммит со своим хэшем.
Текущая ветка сдвигается на этот новый коммит. То есть ветка всегда показывает «последний коммит в этой линии».
Другие ветки не двигаются. Если у тебя есть ветки main и explain-branches, и ты делаешь коммит, находясь в explain-branches, то main останется на старом коммите.
Слияние — это создание нового коммита, у которого два родителя: последний коммит текущей ветки и последний коммит ветки, которую вливают.
