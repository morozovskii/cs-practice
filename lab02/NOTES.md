# cs-practice
Рабочая папка — директория проекта, где хранится репозиторий и отслеживаемые файлы.
Индекс (staging area) — область подготовки изменений: git add lab02/NOTES.md помещает файл в индекс, git diff --staged показывает различия между индексом и последним коммитом.
Коммит — зафиксированное состояние репозитория: git commit -m "Describe local Git states" сохраняет изменения из индекса в историю.
Git — локальная распределённая система контроля версий (работает на машине, фиксирует коммиты, управляет ветками). 
GitHub — облачная платформа для хостинга Git‑репозиториев (обеспечивает удалённое хранение, коллаборацию, PR, CI/CD).
